# Концепция: «Северный Край» (рабочее название)

> Skyrim-подобная ролевая игра **для слабых Android-устройств**.
> Целевой телефон разработки: **Tecno Pova Neo 3** (Helio G85 / Mali-G52 MC2 / 720×1640 90 Гц / 4–8 ГБ).

## 1. Честный разговор о масштабе

Настоящий Skyrim (2011) — это ~37 км² мира, сотни NPC, тысячи объектов, 6 ГБ+ ассетов.
На Helio G85 (≈96 GFLOPS, в ~100 раз слабее ПК того же Skyrim по графике) **полный Skyrim невозможен**.
Но возможен **«мини-Skyrim»** — игра, которая даёт те же ощущения:

| Ощущение из Skyrim | Как получаем мы |
|---|---|
| «Я иду куда хочу» | Бесшовный открытый мир ~0.25 км² на старте, далее растим чанками |
| Живой северный пейзаж | Процедурный низкополигональный террейн, лес, озеро, горы, снег |
| Смена времени суток | Полный цикл день/ночь, цвет неба, туман, звёзды, свет окон |
| Бой от 3-го лица | Меч + блок + перекат, телеграфирование ударов врага |
| Квесты и NPC | Диалоги с ветками, трекер квестов, награды, уровни |
| Лут и инвентарь | Сундуки, трупы, золото, зелья, экипировка |
| Атмосфера «древнего зла» | Драугры в затопленных руинах, волки в лесу |

## 2. Дизайн-столпы (правила, которые нельзя нарушать)

1. **30 FPS стабильно важнее красоты.** Любая фича, которая роняет кадр ниже 33 мс, урезается или получает настройку качества.
2. **Один телефон = один профиль.** Всё тестируется на Tecno Pova Neo 3, а не «в среднем по рынку».
3. **Стиль вместо полигонов.** Низкополигональная графика + плоское затенение + хороший свет и цвет. Это и дешевле, и выглядит цельно.
4. **Управление одним большим пальцем.** Левая рука — движение, правая — камера и бой. Кнопки крупные (≥56 px).
5. **Прототип играбелен всегда.** В любой момент разработки игру можно открыть в браузере телефона и поиграть.

## 4. Ключевые механики v0.1

- Передвижение: ходьба / бег (стамина) / прыжок / плавание
- Бой: лёгкая атака, блок (−70% урона, тратит стамину), откат врага, крит-шанс
- Прокачка: HP, стамина, урон, уровень за XP
- Квест: «Зачистить руины» — убить N драугров → награда золотом и XP
- Диалоги: ветвящийся текст, выдача квеста
- Сохранение: автосейв в localStorage каждые 30 с + ручное

## 5. Чего пока НЕТ (осознанно)

- Огнестрел/магия (будет в v0.3 — «Школа огня» одним заклинанием)
- Крафт, зачарование, стелс, карманные кражи
- Озвучка, полноценный саундтрек (сейчас — синтезированные SFX через WebAudio, 0 МБ ассетов)
- Сюжет и лор больше одного квеста
