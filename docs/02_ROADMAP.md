## Этап 2 — Переход в нативный APK

Решение принимается по итогам этапа 0. Варианты:

| Вариант | Плюсы | Минусы | Вердикт |
|---|---|---|---|
| **A. Остаться в вебе** + Capacitor/TWA → APK | Весь прототип уже готов, 0 переписывания, мгновенные итерации | WebGL вместо Vulkan, нет доступа к части нативных API, сложнее с сохранениями/файлами | **Запасной план, очень рабочий** |
| **B. Godot 4 (Compatibility/GLES3)** → APK | Бесплатный, лёгкий, маленький APK, отличная работа со слабыми GPU, сцена-ориентирован | Переписать логику на GDScript (механику уже знаем из прототипа — перенос быстрый) | **Основной кандидат** |
| **C. Unity (URP)** → APK | Готовые ассеты/анимации из Asset Store, C#, больше туториалов | Тяжёлый редактор, нужен ПК, APK больше, URP на Mali-G52 требует аккуратности | Только если найдутся готовые ассеты |
| **D. Unreal** | Красиво | На Helio G85 практически нерентабельно, APK 300+ МБ | ❌ Отклонено |

> Почему прототип в вебе, а не сразу Godot: в песочнице нет Android SDK/Unity/Godot,
> а веб-прототип **сегодня же** запускается на твоём телефоне по ссылке и даёт реальные
> цифры FPS. Логика (AI, бой, квесты, генерация мира) переносится 1:1 на любой движок.
